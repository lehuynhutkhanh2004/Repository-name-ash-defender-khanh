ASH DEFENDER - MAP READY PACKAGE
================================

Ban da co san mot map 2D phong cach Hero Defense.

Cach dung nhanh:
1. Giai nen file zip.
2. Copy folder Assets/AshDefender_MapReady vao Assets cua project Unity.
3. Mo Unity.
4. Tren menu chon: Tools > Ash Defender > Build Map 01 - Ash Forest.
5. Map se tu xuat hien trong Hierarchy.

Quan trong:
- Khong can gui/chen Library.
- Khong can tu ve Tilemap.
- Enemy co the di theo cac object trong Enemy_Paths.
- Hero co the dat tai cac object trong DeployPoints.
